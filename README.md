🎬 Catálogo de Películas
Descripción

Este proyecto consiste en un programa desarrollado en Java que permite administrar un catálogo de películas mediante un menú interactivo en consola.

Funcionalidades
Agregar películas.
Mostrar películas registradas.
Buscar películas por título.
Modificar información de películas.
Eliminar películas.
Mostrar información del proyecto.
Tecnologías utilizadas
Java
Scanner
Arrays paralelos
Programación estructurada
Cómo ejecutar el proyecto
Descargar el archivo Main.java.
Abrir una terminal en la carpeta del proyecto.
Compilar el programa:
bash
javac Main.java

Ejecutar:
bash
java Main
